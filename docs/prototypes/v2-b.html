What is CLI Pulse?

A developer app for monitoring AI coding usage, quotas, resets, sessions, and cost estimates across providers.

Which platforms are supported?

macOS, iOS, watchOS on the App Store; Android via Google Play internal testing beta.

Does any data leave my device?

API keys, cookies, OAuth tokens, and raw session logs stay local. Only aggregated metrics and metadata sync to your account.
