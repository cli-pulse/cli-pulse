通过 Homebrew 安装 macOS 版本

brew tap cli-pulse/tap
brew trust cli-pulse/tap
brew install --cask cli-pulse

Homebrew 6 需要先执行 brew trust，才能载入第三方 tap 的 cask；否则安装会在 brew tap 后停止。

常见问题

你可能想了解这些

哪些数据留在设备上，哪些数据会同步？

提供商 API Key、会话 Cookie、桥接 OAuth Token 和原始本地会话日志内容留在设备上。聚合后的用量与额度状态可以同步到你的 CLI Pulse 账户，用于跨设备查看。完整的数据分类、边界和控制方式请查看隐私政策。

移动端如何查看和控制 Mac AI-CLI 会话？

配置 Mac helper 和 CLI Pulse 账户后，受支持的移动客户端可以显示受支持 Mac AI-CLI 会话的状态和可用控制动作。实际能力取决于提供商和客户端开放的接口。

CLI Pulse 支持哪些 AI 编程提供商？

CLI Pulse 支持 50+ 个提供商，包括 Claude、Codex、Gemini、Cursor、Copilot、OpenRouter、JetBrains AI、Ollama、Warp 和 Augment。可用指标和控制能力取决于各提供商实际开放的能力。
