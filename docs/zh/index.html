AI 编程用量追踪器

在一个地方查看你所有的 AI 编程用量。

CLI Pulse 汇集你已使用的 AI 提供商和 CLI 工具的用量、额度、重置状态、会话和费用估算——并在 Mac、iPhone、iPad、Apple Watch 和 Android 上展示。你的 Provider API Key 和原始会话日志只留在设备上。

你能看到和做什么

为长期泡在 AI 编程 Agent 里的人准备的聚焦式仪表盘。

用量与额度可见性

在一个地方查看每家提供商的 token 数、请求数、剩余额度和套餐等级，数据来自 Mac 本地 scanner 和 Provider API。

重置状态与提醒

追踪哪些额度已经重置、哪些接近上限，并在提供商快用完时收到提醒——无需逐个打开后台。

费用估算

根据各提供商公布的定价，在本地估算费用。适合发现异常开销，但不能替代官方账单。

会话可见性与控制

macOS helper 运行且你已登录时，可在 iPhone 或 iPad 上查看 Mac 上的实时 AI-CLI 会话，并响应提示或权限请求。

隐私优先

你最敏感的凭证和日志不会离开设备。只有聚合后的数字和运行元数据会同步到你的账户。

  • Provider API Key 留在设备安全存储中
  • Provider 会话 Cookie 和桥接 OAuth Token 留在本地
  • 原始会话日志内容仅在 Mac 上扫描
  • 同步仅使用聚合用量、额度摘要和展示元数据

常见问题

关于产品、数据和支持的快速解答。

CLI Pulse 是一款开发者应用，用于监控你已使用的 AI 提供商和 CLI 工具的用量、额度、重置状态、会话和费用估算。它运行在 macOS、iOS、watchOS 和 Android（Beta）上。
macOS、iPhone、iPad 和 Apple Watch 已在 App Store 上架。Android 通过 Google Play 内部测试 Beta 提供。目前不提供 Windows 和 Linux 客户端。
你的 Provider API Key、会话 Cookie、OAuth Token 和原始会话日志内容留在设备上。CLI Pulse 仅将聚合后的用量指标、额度摘要、费用估算、会话展示元数据和设备心跳信息同步到你的账户。详见 隐私政策 和 数据处理 页面。
不等同。CLI Pulse 根据各提供商公布的定价和你记录的 token / 请求数，在本地估算费用。提供商账单仍是权威来源。估算适合发现趋势，不适合对账。
一般支持请发邮件至 clipulse.support@gmail.com，或在 GitHub Issues 提交 bug 和功能请求。安全披露请私信；详见 安全 页面。
