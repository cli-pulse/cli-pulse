常见问题

CLI Pulse 是什么？

一款开发者应用，用于监控你已使用的 AI 编程提供商和 CLI 工具的用量、额度、重置状态、会话和费用估算。

支持哪些平台？

macOS、iPhone、iPad 和 Apple Watch 已在 App Store 上架。Android 通过 Google Play 内部测试 Beta 提供。目前不提供 Windows 和 Linux 客户端。

数据会离开我的设备吗？

你的 Provider API Key、会话 Cookie、OAuth Token 和原始会话日志内容留在设备上。CLI Pulse 仅将聚合后的用量指标、额度摘要、费用估算、会话展示元数据和设备心跳信息同步到你的账户。详见 隐私政策 和 数据处理 页面。

费用数字是否等同于第一方账单？

不等同。CLI Pulse 根据各提供商公布的定价和你记录的 token / 请求数，在本地估算费用。提供商账单仍是权威来源。估算适合发现趋势，不适合对账。

如何获得支持？

一般支持请发邮件至 clipulse.support@gmail.com，或在 GitHub Issues 提交 bug 和功能请求。安全披露请私信；详见 安全 页面。
