Data Handling

CLI Pulse — Last Updated: October 3, 2026

This page used to keep its own table of the data CLI Pulse handles. That table fell behind the app, and several of its statements were wrong, so it has been removed. The Privacy Policy now lists every kind of data CLI Pulse reads, keeps or sends, where it is kept, and whether it syncs to your account: see Data-by-data breakdown. Your controls and how long data is kept are in the same policy.

What the old table got wrong, as of CLI Pulse 1.55:

  • Only the App Store build reads files through the folder access you grant it. The direct-download build, its background helper and built-in agent, and the Companion CLI are not sandboxed and read the files the Privacy Policy names directly.
  • The app has no button to take back a single folder grant, and the current apps offer no way to change how long ended sessions, alerts and device snapshots are kept.
  • Project folders are not only hashed. While you are signed in and this Mac is paired, each running AI CLI session that CLI Pulse finds syncs its program’s name and its project folder’s name (never the full path), with a keyed hash of that folder’s path.
  • Background sync and Yield Score’s git tracking are both under Settings › Advanced, and only the Companion CLI collects git activity.
  • It said nothing about the Companion CLI or the anonymous install statistics.
